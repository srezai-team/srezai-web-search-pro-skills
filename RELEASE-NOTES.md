# srezai skills 0.6.0

Девять скиллов: шесть инструментальных (как раньше) и три руководства. Главное
изменение — не новые команды, а **правила исполнения**: когда остановиться, что
считать доказательством и как не потратить кредиты вслепую.

## Новые скиллы

- **srezai-build** — встроить srezai в код: выбор канала (CLI/MCP/REST), ключ,
  ошибки по `code`, идемпотентность, лимиты, примеры Node/Python/curl/MCP и
  чек-лист перед релизом.
- **srezai-migrate** — переезд с Tavily / Firecrawl / Exa / SerpAPI: таблица
  соответствия инструментов, что у нас отсутствует (мониторы, snapshot, соцсети),
  grep остатков старого провайдера и проверка после переезда.
- **srezai-eval** — воспроизводимая оценка качества: датасет, манифест прогона,
  ≥3 запуска, судья, p50/p95, учёт фейлов, отчёт «качество × цена × латентность».
  Скилл **user-invocable**: методика не грузится в контекст каждый ход, человек
  запускает её явно.

## Что изменилось в существующих

- **srezai-research**: `verify` вызывается **до** текста, а не после просьбы
  «проверь»; появились «Когда остановиться» (два независимых источника;
  сгенерированный ответ — не источник; цифры и релизы — только первоисточник),
  контракт цитат и `research-workflow.md` с пятью шагами и Failure Recovery.
- **srezai-web**: бюджет проверяется **до** дорогой ступени (`get_usage`, потолок на
  задачу), ошибки 401/402/429 посреди пайплайна описаны как деградация, а не падение;
  `security.md` — единый файл про untrusted-контент, на него ссылаются все скиллы.
- **srezai-read**: большие страницы читаются окнами по `offset`, а `truncated` и
  `skipped[]` проверяются до вывода «данных нет».
- **srezai-site**: критерий «Done when» и честное «обход не гарантирован».
- **srezai-search**, **srezai-transcript**: stop-правила, «не для этого» и связка
  «утверждение из видео → таймкод → verify».

## Оценка качества

`scripts/eval/` — запускаемый harness: 25 позиций (en/ru/zh), frozen-манифест, сырые
результаты по позициям, p50/p95, учёт таймаутов в знаменателе, лист судьи CSV.
По умолчанию dry-run, сеть — только с `--live`. Ограничения метода записаны явно,
а не подразумеваются.

## Поставка

Один контент — шесть манифестов: `.claude-plugin/`, `.codex-plugin/`,
`.cursor-plugin/`, `gemini-extension.json`, `.mcp.json` и `skills/*/SKILL.md` для
любого агента. `manifest.json` содержит SHA-256 каждого скилла — установленную копию
можно сверить с опубликованной.

Стоимость контекста: девять описаний ≈730 токенов (было ≈440 у шести) — это
постоянная плата за то, что агент видит, какой скилл существует. Тело скилла
загружается только при его вызове.

Установка:

```bash
npx skills add srezai-team/srezai-web-search-pro-skills
```

Компаньон — консольная обёртка `srezai-cli` (12 команд, без зависимостей):
`npm install -g srezai-cli`.

Полная документация: `llms.txt`, `docs/tools.md`, references внутри каждого скилла.
