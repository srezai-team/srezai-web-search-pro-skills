# Карточка поставщика: схема extract и правила доказательств

Одна карточка — один кандидат. Поле без источника остаётся `null`, а не
заполняется догадкой.

## Схема для `extract`

```json
{
  "name": "string",
  "name_zh": "string?",
  "city": "string?",
  "province": "string?",
  "address": "string?",
  "market": "string?",
  "phone": "string?",
  "wechat": "string?",
  "website": "string?",
  "products": "string[]?",
  "moq": "string?",
  "price": "string?",
  "price_currency": "string?",
  "founded_year": "number?",
  "employees": "string?",
  "certificates": "string[]?",
  "is_factory": "boolean?",
  "evidence_url": "string?"
}
```

Правила:
- `?` — поле необязательное; отсутствующее значение приходит `null`.
- Цену проси вместе с валютой и единицей (`¥12/шт`, `$2.30 FOB`), иначе она
  бесполезна.
- `is_factory` ставь только по признакам производства (цех, оборудование,
  сертификаты, профиль «manufacturer»); иначе оставь `null` и пометь «трейдер?».
- `evidence_url` — страница, откуда взяты ключевые поля.

## Markdown-таблица для ответа

| Кандидат | Город | Тип | MOQ | Цена | Подтверждено |
|---|---|---|---|---|---|
| 名称 / Name | 深圳 | фабрика? | 500 шт | ¥12/шт (11.2026) | адрес ✓, юрлицо ✗ |

В колонке «Подтверждено» — что именно сверено вторым источником.

## Матрица доказательств

| Поле | Чем подтверждается | Не считается доказательством |
|---|---|---|
| Существование компании | независимый источник + профиль на площадке | одна карточка маркетплейса |
| Адрес | сайт рынка / официальный список / карта + упоминание | адрес из агрегатора без второго источника |
| Производство | страница о заводе: цех, оборудование, сертификаты | слово «factory» в названии |
| MOQ | карточка товара с датой | «от 1 шт» у трейдера |
| Цена | карточка с датой и валютой | цена из статьи/форума |
| Сертификаты | скан/номер на сайте или в реестре | логотип на карточке |

## Пометки достоверности

- `подтверждено` — два независимых источника согласны.
- `одна ссылка` — есть источник, но второй не нашёлся.
- `не подтверждено` — поле пустое или противоречивое.
- `трейдер?` — признаков производства нет.

Эти пометки обязательны: они отличают нашу таблицу от списка ссылок.

## Проверка утверждений

Спорное утверждение (например, «это официальный дилер бренда X») проверяется
через `verify` до попадания в таблицу. `supported` — можно писать, `mixed` и
`unverified` — только с пометкой «не подтверждено».

## Что не делать

- Не схлопывать кандидатов с похожими названиями: в Китае одинаковые имена
  у десятков компаний. Сначала разделить, потом сравнивать.
- Не выдумывать «примерную цену» из общих статей.
- Не переносить поля с карточки одного кандидата на другого.
