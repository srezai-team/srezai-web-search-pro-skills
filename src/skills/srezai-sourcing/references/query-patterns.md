# Шаблоны запросов: RU → EN → ZH

Русский запрос почти никогда не работает на китайских площадках. Переводим
предмет и тип источника, а не весь вопрос.

## Три уровня запроса

1. **EN-обзор:** `[product] manufacturer China [cluster] MOQ` — найти кластер,
   названия компаний и словарь категории.
2. **EN-каталог:** `site:made-in-china.com [product]`, `site:alibaba.com [product] factory`.
3. **ZH-первоисточник:** `[产品] 工厂 [城市]`, `[产品] 批发市场`, `[产品] 起订量 价格`.

## Словарь категории (дополнять по факту)

| RU | EN | ZH |
|---|---|---|
| фабрика / завод | factory / manufacturer | 工厂 / 厂家 / 制造商 |
| поставщик | supplier | 供应商 |
| оптом / опт | wholesale | 批发 |
| рынок (торговый) | market | 市场 / 商城 |
| минимальный заказ | MOQ | 起订量 / 起批量 |
| цена FOB | FOB price | 离岸价 |
| образец | sample | 样品 |
| сертификат | certificate | 认证 / 证书 |
| производственная линия | production line | 生产线 |
| адрес | address | 地址 |
| провинция / город | province / city | 省 / 市 |

## Примеры по типам товаров

**Электроника / мини-ПК**
```
mini pc manufacturer Shenzhen OEM ODM
site:1688.com 迷你主机 工厂 深圳
深圳 华强北 迷你主机 批发 市场
```

**Товары народного потребления (зонты, посуда)**
```
reverse umbrella factory China MOQ
site:zhihu.com 雨伞 批发 义乌
义乌 国际商贸城 雨伞 摊位 地址
```

**Промышленные кластеры**
```
[product] industry cluster China city list
[城市] [产品] 产业集群 名录
site:gov.cn [城市] [产品] 产业
```

## Как сужать, не теряя смысл

- Сначала **тип источника** (`factory`, `wholesale market`, `manufacturer`), потом
  география, потом MOQ/цена.
- Географию задавай городом/провинцией, а не «China»: в Китае кластеры локальны.
- `2026` в запросе помогает отсечь старые статьи о ценах — но дату всё равно
  проверяй по странице, а не по запросу.
- Если 2–3 запроса подряд пустые, меняй формулировку предмета (синоним или
  отраслевой термин), а не добавляй фильтры.

## Чего избегать

- Дословного перевода вопроса: «где купить зонт оптом в Китае недорого» на ZH
  даст статьи, а не фабрики.
- Латиницы в ZH-запросе без нужды: `雨伞` работает, `umbrella` — нет.
- Смешивания в одном запросе города, MOQ и сертификата: три отдельных запроса
  дадут больше.
